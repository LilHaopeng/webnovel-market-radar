# 跨平台市场基线、读者画像与信号甄别参考

> **重要声明**：本文件汇总自各主流网文平台的历史公开样本与编辑经验，**仅作为分析对照基线与兜底假设**。平台推荐算法、收稿偏好、字数节点与变现规则变化很快，实际选题前**必须以本次实时扫榜样本或编辑最新口径校验**；若无实时样本直接引用本文件，输出可行性一律封顶「中」。

## 1. 短篇赛道跨平台基线对照（`--track short`）

短篇的核心商业逻辑是**单篇完读率 + 情绪交付 + 点击转化（标题/导语） + 传播分享**，风口往往数周迭代一次。

| 维度 | 番茄短故事 / 短中篇 | 知乎盐言故事 | 七猫短篇 | 点众短篇 | 黑岩短篇 |
|---|---|---|---|---|---|
| **常见字数** | 0.8–3 万字超短篇；2–5 万字微短剧短中篇 | 0.5–1.5 万字（中位约 1.2 万） | 1–2 万字（常 7–19 章） | 1–2 万字（常 5–10 章） | 0.8–4 万字 |
| **常见人称** | 第一 / 第三人称均常见 | 第一人称强限定（古言偶用第三） | 第一人称占比极高 | 第一人称占比极高 | 女频偏第一人称，男频混合 |
| **引号规范** | 全角双引号 `“”` | **直角引号 `「」`**（嵌套 `『』`） | `“”` 或 `「」` | `“”` 为主 | `“”` 或 `「」` |
| **推进体感** | 手机短段、高概念脑洞、强爽点叠加 | 情绪拉扯强、短句利落、专业细节扎实、后劲大 | 强情绪推进、重生/逆袭/情感推拉 | 极短段（1–2 句）、高频转折、对话高度功能化 | 极端情绪冲击、快节奏高密反转 |
| **导语/简介** | 120–260 字冲突前置导语 | **200–500 字独立微小说**（直接决定转化） | 120–260 字强情绪导语（常带最伤人台词） | 150–300 字浓缩前 1/3 精华 | 120–300 字极端羞辱/倒计时+亮底牌 |
| **常见反转位** | 前 1500 字小验证 + 多轮叠加反转 | 70%–85% 位置核心大反转 | 压抑 → 觉醒 → 密集打脸反杀 | 每 2–3 节小转折 + 终局掀桌 | 300–500 字即抛强冲击/小反转 |
| **适配写作配置** | `flash` 或 `microdrama`；`dialogue` / `first_person` / `rules` | `flash`；多为 `first_person` + `zhihu` | `flash`；`first_person` / `dialogue` | `flash`；`first_person` / `dialogue` | `flash` 或 `microdrama`；`dialogue` / `first_person` |

### 短篇开头与标题观察焦点（扫榜时必提炼）
- **开头 3 句话**：看当前榜上高频用哪类入局（极端羞辱当场发生 / 一句话反常识规则炸弹 / 重生回关键节点拍板 / 诡异反常细节）。
- **标题规律**：番茄/七猫/点众/黑岩偏**事件反杀直给型**（`[极端事件/脑洞异常] + [反击结果]`）；知乎盐言偏**精短反差/提问型**（常 6–14 字）。
- **结局比例**：统计当前样本中 HE（爽感圆满/新局面）、BE（意难平/余韵）与开放式/回马枪的比例，按平台预期做选择。

## 2. 长篇赛道跨平台基线对照（`--track long`）

长篇的核心商业逻辑是**长线追读留存 + 平台流量机制匹配 + 可持续的核心循环**。

| 平台 | 商业模式与核心指标 | 主力读者与核心期待 | 扫榜重点关注 |
|---|---|---|---|
| **番茄小说** | 免费流量制；看**在读数、追更人数、完读率** | 大众下沉与泛网文读者；追求高概念脑洞、开局快爽、零门槛 | 新书榜与阅读榜在读差距、简介开头 `【标签+标签】` 组合、**警惕 AI 同质化扎堆风险** |
| **起点中文网** | 订阅付费制；看**追读率、月票、畅销、三江推荐** | 男频重度老白占比高；看重升级体系、世界感、智商在线与长期期待感 | 新人签约新书榜、签约新书榜、三江推荐，观察书名点题度与新金手指变体 |
| **七猫小说** | 免费流量制；看**热度、大热榜/新书榜/完结榜** | 大众读者（女频情绪流占比突出）；快节奏、强情感拉扯、爽点直给 | 大热榜日/月榜交替速度、高情绪标签组合 |
| **晋江文学城** | 付费积分制；看**收藏数、营养液、积分** | 女频/言情/纯爱精品读者；看重人设张力、主体性、文案安全感与感情层次 | 收入金榜/月榜/新手金榜，**必须点进详情页核对收藏与营养液** |
| **刺猬猫** | 付费二次元社区；看**点击、收藏、追读、月票** | 15–25 岁 ACG 读者；看重有趣、人设鲜明、反套路玩梗与互动感 | 单页多榜交叉，观察人设卖点与同人/轻小说新切口 |

> 平台推荐测试字数、签约节点、保底分成等政策变化频繁，任何商业预判须以平台最新官方公告或编辑口径为准，绝不把过时经验数字写成保证。

## 3. 通用信号甄别与选题方法论

### 3.1 新元素三级甄别（判断该不该跟）
| 信号级别 | 判定标准 | 选题策略 |
|---|---|---|
| **新题材（罕见）** | 跨榜单、跨作者出现多个高热度重复样本 | 重点跟进，但须验证自身素材与体量承载力 |
| **新金手指 / 新脑洞机制（高性价比）** | 旧题材内出现新规则玩法（如条件→反馈机制翻新、概率/叠加/逆向利用） | **最推荐切入点**：借成熟受众基本盘 + 换新脑洞壳打出差异化 |
| **新噱头 / 表面热词（高风险）** | 仅靠书名热词或单一桥段吸睛，同质化极快 | 极易被 AI 批量洗烂；若无底层机制升级与反转设计，主动降优先级 |

### 3.2 「85% 熟悉 + 15% 反常识惊喜」与三层边界圈
- 读者买单的往往不是 100% 陌生概念，而是**用市场已验证的情绪母题与熟悉背景（85%）承载一个极其锐利的反常识脑洞/规则错位（15%）**——绝不做“照搬剧情换皮”，而是**借情绪骨架 + 彻底原创规则、人设与反转角度**。
- **三层边界圈（防写串味）**：
  1. **题材圈**（都市 / 古言 / 悬疑 / 玄幻等大类）；
  2. **流派圈**（脑洞打脸 / 规则怪谈 / 世情复仇 / 种田经营等）；
  3. **核心梗圈**（本篇最核心的卖点与情绪承诺，正文绝不能跑偏到把核心卖点丢掉）。

### 3.3 读者共鸣 70 / 20 / 10 观察框架
分析榜单样本为什么引发共鸣与转发时，拆三层触发源：
- **70% 共同经验 / 怀旧锚点**：校园、原生家庭、职场规则、熟悉人情世故；
- **20% 当下现实压力**：职场内卷、婚恋算计、消费/房产焦虑、人际消耗；
- **10% 近期热梗 / 社会议题**：新鲜切口与传播话题度。
