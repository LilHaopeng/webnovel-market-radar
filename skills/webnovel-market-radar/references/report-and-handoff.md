# 扫榜输出契约、选题四步漏斗与下游写作接口

在整理扫榜报告、起草 `选题简报.md` 以及向写作技能交接时读取。

---

## 1. 标准落盘目录

每次扫榜默认落盘到工作区下的独立目录（不污染任何具体小说项目）：

```text
扫榜/{YYYYMMDD}_{平台}_{short|long|both}/
├── 扫榜报告.md         # 实采样本汇总、数据质量状态、趋势与新元素分析
└── 选题简报.md         # 2–3 个可执行选题 + 面向下游写作技能的标准交接块
```

---

## 2. `扫榜报告.md` 必填结构

文件头必须保留以下元数据行（供 `validate_scan.py` 自动核验）：

```markdown
# 网文扫榜报告：{平台}（{short|long|both}）

- 扫榜日期：{YYYY-MM-DD}
- 赛道类型：{short / long / both}
- 采集方式：{ego-browser / builtin-browser / user-input / baseline}
- 数据来源：{可核验榜单 URL 列表，或“用户粘贴样本” / “内置历史参考基线”}
- 有效样本数：{N}
- 数据质量：{OK / 数据稀疏 / 内置参考降级}
- 建议复扫时间：{短篇 +2~4周 / 长篇 +1~2月}
- 问题摘要：{无 / 缺失或跳过的平台与原因}
```

正文必备模块：
1. **市场概况（一句话核心判断）**
2. **情绪 / 题材热度排行表**（短篇必含情绪类型 + 样本数 + 趋势 + 代表作；长篇必含题材 + 样本数 + 趋势 + 代表作）
3. **跨样本模式与新元素提取**（至少区分为：高频设定/金手指机制、高频开篇切入点、标题与导语规律；严禁只抄单本个例）
4. **风口与饱和预警**（正在爆发 / 即将起风 / 即将饱和或 AI 同质化高危区）
5. **清洗后样本明细表**（保留排名、书名、标签/题材、核心公开指标、≤120 字截断简介）

---

## 3. `选题简报.md` 四步漏斗与质量门硬规则

每个推荐选题（建议 2–3 个，按可行性从高到低排）必须走完四步：
1. **能爆假设（标明待验证）**：基于多本重复样本提炼“它吃的是哪波情绪痛点与期待感”，不把单本偶然上榜吹成必爆规律。
2. **市场验证**：说明本次样本中有几本同类、趋势方向（↑/→/↓）以及已观察到的同质化/扑街风险。
3. **差异化原创切口（防洗稿核心）**：明确指出“保留哪层情绪骨架”以及“强制置换哪两项以上底层要素（新奇观规则 / 新职业处境 / 新反转角度）”。
4. **可行性评级 + 失败风险 + 最小验证动作**：
   - **高**：本次实采数据质量为 `OK`（样本 ≥15，小平台 ≥10）+ 趋势 `↑` 或 `→` + 有清晰差异化切口；
   - **中**：样本足够但趋势 `↓`、差异化待打磨、**或数据质量为 `数据稀疏` / `内置参考降级`（强制封顶「中」）**；
   - **低**：赛道明显饱和、AI 同质化严重或与作者约束不匹配。

---

## 4. 下游写作技能兼容交接块（`选题简报.md` 必备）

为了无需二次翻译就能直接喂给写作 Skill，每个推荐选题下方统一附带结构化交接块：

```markdown
### 选题 1：{一句话选题方向}
- 推荐写作管线：`webnovel-short-studio`（5万字以内短篇/微短剧） 或 `story-world-architect → story-outline-architect → story-prose-writer`（厚重长篇）
- 目标平台：{fanqie / zhihu / qimao / dianzhong / heiyan / qidian / jjwxc / ciweimao}
- 建议体量模板：{flash（0.8–3万字超短篇） / microdrama（2–5万字微短剧短中篇） / long（30万字+长篇）}
- 建议推进叙事类型：{dialogue / first_person / rules / 传统多维叙事}
- 建议对话引号：{“” / 「」（知乎盐言）}
- 题材与情绪组合：{主题材 + 核心情绪拉扯}
- 核心情绪痛点：{读者最买单的缺口}
- 能爆假设：{跨样本总结的爆点逻辑}（`待试写/市场验证`）
- 市场验证：{同类样本 N 本 + 趋势 ↑/→/↓ + 同质化观察}
- 差异化原创脑洞切口：{强制置换的新规则 / 新身份 / 新反转方向，严禁照抄榜上原书剧情}
- 标题与导语参考方向：{适配目标平台的标题风格与导语字数建议}
- 可行性：{高 / 中 / 低} — {依据}
- 失败风险：{最容易崩的点}
- 最小验证动作：{如“先用 webnovel-short-studio 跑脑洞4问压测并试写前500字定调”}
```

### 下游如何直接消费
- **对接 `webnovel-short-studio`**：直接把 `选题简报.md` 路径传给 `webnovel-short-studio`，其 `hook` 阶段自动读取平台、体量模板（`flash/microdrama`）、推进类型（`dialogue/first_person/rules`）、引号规范与情绪痛点，并跳过照抄步骤直接进入「脑洞 4 问压测与原创规则卡」。
- **对接传统长篇三件套**：把 `选题简报.md`（兼容原 `选题决策.md` 语义）放到项目根目录，作为 `story-world-architect` / `story-outline-architect` 的立项参考输入。
