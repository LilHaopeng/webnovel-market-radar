# 浏览器手动模拟采榜指南与数据清洗规则

在执行实时榜单采集时读取。本指南彻底弃用脆弱的硬编码 CDP 爬虫脚本，改为**可视化浏览器人机协同采集**，兼容反爬变化与登录态需求。

---

## 1. 浏览器工具选择顺序

### 方式 1：优先使用本机 `ego-browser`
1. 先检测环境中是否存在 `ego-browser` 命令（Windows 可检查 `Get-Command ego-browser`）。
2. 若存在，**先运行 `ego-browser skill`** 读取与当前已安装版本匹配的完整操作指南（切勿凭旧记忆猜子命令）。
3. 使用 Ego Browser 打开目标平台公开榜单页，复用用户浏览器上下文进行自然浏览、点击切换男/女频或榜种 Tab、滚动加载更多条目，并在需要核对简介/标签/公开热度时点进作品公开详情页查看。

### 方式 2：回退使用内置 `browser` 子代理
- 若当前环境未安装 `ego-browser`，或用户要求使用内置浏览器，直接委派 `browser` 子代理打开目标榜单 URL，模拟点击切换分类、向下滚动并提取页面可见榜单信息。

### 方式 3：用户投喂与公开检索
- 用户已有榜单截图、复制粘贴文本或历史扫榜 Markdown 时，直接解析整理，不必重复开浏览器。
- 若个别平台页面受限，可用 `search_web` 检索近期公开的榜单汇总、平台官方推文或编辑收稿风向作为补充，并在来源栏明确注明“公开检索补充”。

---

## 2. 合规与人机协同边界（必须严守）

- **遇到登录墙 / 会员付费墙**：立即暂停并告知用户需要在浏览器窗口中登录自己的账号，等用户确认登录后再继续。
- **遇到滑动验证码 / 人机校验 / 反爬拦截页**：立即停止自动操作，明确汇报拦截情况并由用户在可见浏览器中亲自完成，**严禁尝试破解、绕过或脚本强刷**。
- **采集颗粒度红线**：只采榜单列表页和公开详情页的元数据（排名、书名、作者、题材/标签、状态、字数、在读/热度/收藏/推荐等公开指标、截断 ≤120 字的公开简介）；**严禁打开或抓取付费章节正文**。
- **单平台失败不阻塞全局**：同时扫多个平台时，若某平台因需登录或不可达无法采集，在报告里标明 `SKIP（原因）`，继续完成其余平台。

## 4. 数据清洗与质量门检查（写入 `扫榜报告.md` 前必做）

1. **去污染**：删除平台固定模板套话（如“提供XXX完整版在线免费阅读”“点击立即阅读”“上一页/下一页”等）。
2. **简介截断**：清洗后的公开简介若超过 120 字，在就近的句号/问号/感叹号处截断并加 `...`，只保留卖点骨架。
3. **空值透明化**：未获取到的字段一律标 `[待补]`，严禁凭空编造在读数、收藏数或字数。
4. **有效条目判定**：至少包含「排名/位置 + 书名 + 核心指标或题材简介」才算 1 条有效样本；无效/乱码条目移除并重算有效数。
5. **标注数据质量状态**（写入报告头部，供 `validate_scan.py` 自动检查）：
   - `OK`：主流平台有效条目 ≥ 15（小平台/细分短篇榜 ≥ 10），核心指标清晰；
   - `数据稀疏`：实时采得样本但低于上述数量门槛（下游所有对应选题可行性封顶「中」）；
   - `内置参考降级`：本次未采到实时样本，纯基于历史参考基线推演（下游所有对应选题可行性封顶「中」）。
